# Partnership & Revenue Tracker

## Overview
This project tracks revenue generated from business partnerships, evaluates partner performance, and identifies growth opportunities for business development teams.

## Tools Used
- Python (pandas)
- Excel
- Tableau (for visualization)

## Dataset
- Partner_ID
- Partner_Name
- Region
- Revenue
- Deals_Closed
- Industry
- Partnership_Start

## Key Features
- Calculates revenue per deal for each partner
- Creates a performance score to rank partners
- Identifies top-performing partners and regions
- Exports cleaned data for Tableau dashboards

## Business Value
- Supports strategic investment in high-performing partnerships
- Helps prioritize partnership management efforts
- Provides data-driven insights for business expansion

## Future Enhancements
- Include ROI per partner
- Track partnership duration vs. revenue growth
- Forecast future revenue from top partners
